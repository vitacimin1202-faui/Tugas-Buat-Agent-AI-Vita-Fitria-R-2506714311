Pedoman Ilmiah & Panduan Perhitungan SCCS 12th Revision

1. Rumus Systemic Exposure Dose (SED)

Dosis paparan sistemik harian per kilogram berat badan dihitung dengan:

SED = [ A × 1000 × (C / 100) × (DAp / 100) × R ] / BW
  • A = Jumlah aplikasi harian produk baku SCCS (g/hari).
  • C = Konsentrasi bahan baku dalam formula (%).
  • DAp = Persentase absorpsi dermal (Default konservatif SCCS: 50%).
  • R = Retention factor (1.0 untuk leave-on; 0.01 untuk bilas/shampoo).
  • BW = Berat badan konsumen (60 kg dewasa; 5 kg bayi).

2. Penyesuaian Bioavailabilitas ($PoD_{sys}$)

Koreksi rute pemberian jika menggunakan uji toksisitas oral 90 hari:

NOAEL_sys = NOAEL_oral × (Abs_oral / 100)
  • Jika $Abs_{oral} \ge 50\%$, nilai $NOAEL_{sys} = NOAEL_{oral}$.
  • Jika $Abs_{oral} < 50\%$, dilakukan koreksi sesuai persentase.
  • Jika data tidak tersedia, gunakan default SCCS 50%.

3. Kriteria Keberterimaan MoS ≥ 100

Ambang batas keamanan 100 diturunkan dari Default Assessment Factor (DAF):

MoS = PoD_sys / SED ≥ 100
  • Inter-species (Hewan ke Manusia): $4.0 \times 2.5 = 10$
  • Intra-species (Sensitivitas antar individu): $3.2 \times 3.16 = 10$
  • Total Safety Factor: $10 \times 10 = 100$.

4. Hazard Index (HI) Paparan Kumulatif

Untuk bahan dengan cara kerja serupa (misalnya pengawet ester paraben):

HI = ∑ (1 / MoS_i) × 100 ≤ 1.0
  • Jika $HI \le 1.0$, kombinasi bahan dinyatakan AMAN.
  • Jika $HI > 1.0$, terdapat kekhawatiran risiko toksisitas kumulatif.
